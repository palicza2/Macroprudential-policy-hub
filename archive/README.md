# Archive

Ez a mappa elavult vagy jelenleg nem használt fájlokat tartalmaz.

## Tartalom

### `run_all.R`
- R script a régi pipeline futtatásához
- **Státusz:** Elavult (most Python pipeline van)

### `supabase_migration/`
- Python-based Supabase migration modulok
- **Státusz:** Elavult (most SQL migration fájlok vannak a `migrations/` mappában)
- **Megjegyzés:** Még használatban van a `pipeline/writers/supabase_writer.py`-ban, de dokumentálatlan

### `output/`
- Generált PNG fájlok
- **Státusz:** Ellenőrizni kell, hogy használják-e
